# تحدي الثنائي — منافسة بين طالبين على جهاز واحد

## التشغيل
- افتح `index.html` مباشرة في المتصفح (يعمل دون إنترنت)، ويُفضّل عرضه على شاشة العرض أو شاشة لمس كبيرة.
- المعلم يختار: **الصف ← المادة ← الفصل الدراسي ← الوحدة ← الدروس** (أسئلة الدروس المختارة تُجمع في مباراة واحدة).
- ثم «إعداد المباراة»: اسم كل لاعب وشخصيته، وعدد الأسئلة (5/10/15/الكل)، ووقت كل سؤال (10/20/30 ثانية).

## طريقة اللعب (نظام الجرس)
- لكل طالب **زرّ جرس واحد** كبير في نصفه من الشاشة.
- يظهر السؤال وخياراته للجميع مع 3 ثوانٍ للقراءة، ثم يُفتح الجرسان معًا (الضغط المبكر لا يُحتسب).
- من يضغط جرسه أولًا يحصل على دور الإجابة خلال 8 ثوانٍ.
- الإجابة الصحيحة تكسب النقطة. الخاطئة أو انتهاء الوقت: ينتقل الدور مباشرة للمنافس، ولا يُعلَّم الخيار الخاطئ.
- إذا أخطأ الاثنان أو لم يضغط أحد: لا نقطة، ولا تظهر الإجابة الصحيحة، ويعود السؤال بعد 3–5 أسئلة أخرى. السؤال المجاب عنه صحيحًا لا يتكرر.
- نهاية المباراة: إعلان الفائز (أو التعادل) وجدول مقارنة.

## التحكم
- **اللمس:** كل طالب يضغط جرسه، ومن حصل على الدور يلمس إجابته.
- **لوحة المفاتيح:** جرس اللاعب الأول (يمين) = Enter أو L، جرس اللاعب الثاني (يسار) = Space أو A، والإجابة بالأرقام 1–4.
- **الهاتف أو الجهاز اللوحي عموديًا:** وضع الطاولة؛ جرس اللاعب الثاني في الأعلى مقلوبًا ليجلس الطالبان متقابلين.

## بنية المشروع
```
index.html        الواجهات
css/style.css     التصميم
js/config.js      الإعدادات (عدد الأسئلة، الوقت، بيانات المعلم)
js/questions.js   مدير الأسئلة (منع التكرار + إعادة الخاطئ)
js/duo.js         منطق المباراة والواجهات
js/audio.js       الموسيقى والمؤثرات
data/             بنك الأسئلة المُولّد من ملف Google Sheet
tools/parse.py    تحويل ملف الأسئلة إلى ملفات data
tests/            الاختبارات (node tests/duo.test.js بعد تشغيل خادم على 8767)
```
