# غوص اللؤلؤ

مراجعة سريعة لطالب واحد أو للصف: غوّاص ينزل إلى قاع البحر.
- **صحيحة:** لؤلؤة جديدة، والغوّاص ينزل 10 أمتار أعمق.
- **خاطئة أو انتهاء الوقت:** تنقص أسطوانة أكسجين (3 أسطوانات).
- الوصول إلى العمق المطلوب (50/100/150 م) يفتح صندوق الكنز؛ نفاد الأكسجين يُعيد الغوّاص إلى السطح.
- يُحفظ أفضل عمق لكل مجموعة دروس على الجهاز.

## التشغيل
- افتح `index.html` مباشرة في المتصفح (يعمل دون إنترنت)، أو ارفع المجلد إلى موقعك.
- المعلم يختار: **الصف ← المادة ← الفصل الدراسي ← الوحدة ← الدروس**، ثم إعدادات اللعبة.
- الأسئلة من بنك الأسئلة (ملف Google Sheet)؛ لا تظهر الإجابة الصحيحة عند الخطأ، ويعود السؤال الخاطئ بعد 3–5 أسئلة أخرى، ولا يتكرر السؤال الصحيح في الجلسة.
- اسم المعلم وحساب Instagram اختياريان ويظهران في اللعبة.

## النشر للطلاب: رابط أو حزمة SCORM
- «نسخ رابط للطلاب»: رابط يفتح اللعبة مباشرة على الدروس المختارة.
- «تنزيل حزمة SCORM»: ملف zip (SCORM 1.2) يُرفع في Moodle وغيره، ويسجّل نسبة الإجابات الصحيحة والحالة ومدة الجلسة (`js/scorm.js`).

## الملفات
