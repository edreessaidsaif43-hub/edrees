# عدّاء الكورنيش 3D — لعبة تعليمية فردية

لعبة جري ثلاثية الأبعاد على كورنيش مطرح عند الغروب: البحر وسفن الداو والتلال، والبيوت القديمة بشرفاتها الخشبية، وبوابة سوق مطرح والمسجد، وحركة السير (تاكسي عُماني، سيارات، حافلة) ومسار الدراجات، وخط النهاية عند قلعة مطرح.
- يختار الطالب شخصيته (الولد بالدشداشة والكمة، أو البنت بالمريول الكحلي، أو بالمريول العنابي) ويكتب اسمه اختياريًا.
- يظهر السؤال وتقترب بوابة على كل فتحة منها خيار؛ يدخل الطالب فتحة الإجابة التي يختارها.
- **صحيحة:** دفعة سرعة و5 عملات، ويتقدّم شريط الطريق نحو القلعة.
- **خاطئة:** يتعثّر العدّاء ويخسر قلبًا؛ لا تظهر الإجابة الصحيحة، ويعود السؤال بعد 3–5 أسئلة.
- بين البوابات: عملات وعربات وحواجز (الاصطدام يبطئ فقط).
- التحكم: الأسهم ← → والقفز ↑ أو المسافة؛ السحب بالإصبع؛ أو الأزرار أسفل الشاشة (للهاتف والسبورة التفاعلية).
- الإعدادات: عدد الإجابات للوصول إلى القلعة (8/12/16)، وقت الوصول إلى البوابة (10/15/20 ثانية)، السرعة، القلوب (3/5/بلا حدود)، جودة الرسوم.
- أصوات: هدير السيارات عند مرورها، بوق التاكسي، جرس الدراجات، موج البحر، العملات والقفز.

## التشغيل والنشر
- افتح `index.html` مباشرة (يعمل دون إنترنت؛ مكتبة Three.js مضمّنة في `js/run-engine.js`).
- يحتاج متصفحًا يدعم WebGL.
- «نسخ رابط للطلاب» و«تنزيل حزمة SCORM» في شاشة المعلم.
- مصدر المحرك ثلاثي الأبعاد في مجلد `src` (يُجمَّع بـ esbuild).
- الاختبار: شغّل خادمًا محليًا على 8809 ثم `node tests/corniche3d.test.js`.
