# بناء القلعة

لعبة للصف كله، مناسبة للصفوف الصغيرة (بلا وقت افتراضيًا، أزرار كبيرة).
- اختر **قلعة نزوى** أو **قلعة بهلاء**، وعدد الأحجار (8/10/15/20).
- **صحيحة:** يُضاف حجر (مجموعة طوب) إلى القلعة من الأسفل إلى الأعلى، مع شريط تقدّم.
- **خاطئة:** يسقط الحجر ولا يُضاف.
- عند الاكتمال تُفتح البوابة ويُرفع العلم، وتظهر معلومة عن القلعة.
- المعلم يضغط «السؤال التالي» (أو المسافة) بعد مناقشة كل سؤال.

## التشغيل
- افتح `index.html` مباشرة في المتصفح (يعمل دون إنترنت)، أو ارفع المجلد إلى موقعك.
- المعلم يختار: **الصف ← المادة ← الفصل الدراسي ← الوحدة ← الدروس**، ثم إعدادات اللعبة.
- الأسئلة من بنك الأسئلة (ملف Google Sheet)؛ لا تظهر الإجابة الصحيحة عند الخطأ، ويعود السؤال الخاطئ بعد 3–5 أسئلة أخرى، ولا يتكرر السؤال الصحيح في الجلسة.
- اسم المعلم وحساب Instagram اختياريان ويظهران في اللعبة.

## النشر للطلاب: رابط أو حزمة SCORM
- «نسخ رابط للطلاب»: رابط يفتح اللعبة مباشرة على الدروس المختارة.
- «تنزيل حزمة SCORM»: ملف zip (SCORM 1.2) يُرفع في Moodle وغيره، ويسجّل نسبة الإجابات الصحيحة والحالة ومدة الجلسة (`js/scorm.js`).

## الملفات
```
index.html / css/style.css / js/config.js (الإعدادات) / js/castle.js (منطق اللعبة)
js/questions.js (مدير الأسئلة) / js/audio.js (الصوت) / js/scorm.js (SCORM) / data/ (بنك الأسئلة)
tests/castle.test.js (شغّل خادمًا محليًا على المنفذ 8802 ثم node tests/castle.test.js)
```
