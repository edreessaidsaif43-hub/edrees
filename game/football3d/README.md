# ملعب المعرفة 3D — لعبة تعليمية

مباراة كرة قدم ثلاثية الأبعاد بين فريقين في ملعب ليلي (مدرّجات بجمهور بألوان الفريقين، أعلام عُمان، أبراج إضاءة، شاشتان عملاقتان، لوحات إعلانية).
- جولة كاميرا حول الملعب ثم صافرة البداية؛ يهاجم الفريقان بالتناوب، وقبل كل هجمة سؤال للفريق المهاجم.
- **صحيحة:** هجمة (انطلاقة فردية أو تمريرة وتسديدة) تنتهي بهدف، مع لقطة من خلف الشباك واحتفال اللاعبين وقفز الجمهور.
- **خاطئة:** يقطع المدافع الكرة أو يتصدّى الحارس أو ترتطم الكرة بالقائم؛ لا تظهر الإجابة الصحيحة، ويعود السؤال بعد 3–5 أسئلة.
- عدد الهجمات لكل فريق 3 أو 5 أو 8؛ تنتهي المباراة مبكرًا إذا حُسمت، وعند التعادل جولات «الهدف الذهبي».
- شاشة اللعب: لوحة النتيجة، رقم الهجمة، رقم السؤال، بطاقة لكل فريق بسجل هجماته (⚽ هدف / ✕ ضائعة)، والشاشتان في الملعب تعرضان النتيجة.
- جودة الرسوم: عالية / متوسطة / خفيفة. لاعبون ثلاثيو الأبعاد ببشرة فاتحة وقمصان مرقّمة؛ وشخصيات المنصة فقط في الشارات فوق اللاعبين وفي لوحات الفريقين.

## التشغيل والنشر
- افتح `index.html` مباشرة (يعمل دون إنترنت؛ مكتبة Three.js مضمّنة في `js/foot-engine.js`).
- يحتاج متصفحًا يدعم WebGL (Chrome أو Edge أو Safari حديث).
- «نسخ رابط للطلاب» و«تنزيل حزمة SCORM» في شاشة المعلم.
- مصدر المحرك ثلاثي الأبعاد في مجلد `src` (يُجمَّع بـ esbuild).
- الاختبار: شغّل خادمًا محليًا على 8808 ثم `node tests/football3d.test.js`.
