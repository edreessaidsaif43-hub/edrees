# سباق المعرفة 3D — لعبة تعليمية

سباق سيارات ثلاثي الأبعاد بين فريقين على حلبة عُمانية (جبال الحجر، قلعة، مسجد، نخيل، مدرّجات وجمهور).
- تنطلق السيارتان بعد أضواء الانطلاق، ويجيب الفريقان بالتناوب؛ والكاميرا خلف سيارة الفريق صاحب الدور.
- **صحيحة:** دفعة نيترو (لهب وخطوط سرعة) تقدّم سيارة الفريق.
- **خاطئة:** انزلاق ودخان وتراجع بسيط؛ لا تظهر الإجابة الصحيحة، ويعود السؤال بعد 3–5 أسئلة.
- يفوز أول فريق يجمع 4 أو 6 أو 8 إجابات صحيحة، فينطلق نحو خط النهاية مع احتفال.
- شاشة اللعب: شريط تقدّم السباق، رقم السؤال، عدّاد السرعة، لوحة لكل فريق (المركز، الإجابات الصحيحة، مؤشر النيترو)، وشاشة المدرّج الكبيرة تعرض الترتيب.
- جودة الرسوم: عالية / متوسطة / خفيفة (للأجهزة الأضعف والهواتف).
- السائقون من شخصيات المنصة فقط (خوذة بلون الفريق + شارة الشخصية فوق السيارة).

## التشغيل والنشر
- افتح `index.html` مباشرة (يعمل دون إنترنت؛ مكتبة Three.js مضمّنة في `js/race-engine.js`).
- يحتاج متصفحًا يدعم WebGL (Chrome أو Edge أو Safari حديث).
- «نسخ رابط للطلاب» و«تنزيل حزمة SCORM» في شاشة المعلم.
- مصدر المحرك ثلاثي الأبعاد في مجلد `src` بالمشروع الأصلي (يُجمَّع بـ esbuild).
- الاختبار: شغّل خادمًا محليًا على 8807 ثم `node tests/race3d.test.js`.
