# رحلة المعرفة — لعبة منصات مرتبطة ببنك الأسئلة

## التشغيل
- افتح `index.html` مباشرة في المتصفح (يعمل دون إنترنت ودون خادم)، أو ارفع المجلد كاملًا على أي استضافة مواقع ثابتة.
- المعلم يختار: **الصف ← المادة ← الفصل الدراسي ← الوحدة ← الدروس**، ثم «إنشاء اللعبة».
- «نسخ رابط للطلاب» ينشئ رابطًا يفتح اللعبة مباشرة على الدروس المختارة (مع بيانات المعلم إن وُجدت).

## بنية المشروع
```
index.html            الواجهات
css/style.css         التصميم (RTL ومتجاوب)
js/config.js          الإعدادات: النقاط، الأرواح، الوقت، بيانات المعلم الافتراضية
js/questions.js       مدير الأسئلة (منع التكرار + إعادة الخاطئ بعد 3–5 أسئلة)
js/level.js           مولّد المراحل بتدرّج الصعوبة
js/render.js          الرسومات الأصلية (برمجية بالكامل)
js/game.js            الفيزياء، الذهبيات، الأرواح، نقاط الحفظ
js/audio.js           الموسيقى والمؤثرات (مولّدة برمجيًا)
js/ui.js              الإعداد، شاشة البداية، الأسئلة، النتائج، الحفظ المحلي
js/demo.js            وضع العرض التلقائي (?demo=1) للتسجيل فقط
data/index.js         فهرس الصفوف والمواد
data/grades/gNN.js    بنك أسئلة كل صف (مُولّد من ملف Google Sheet)
tools/parse.py        أداة تحويل ملف الأسئلة إلى ملفات data
tests/                اختبارات المنطق
```

## تحديث الأسئلة
1. حدّث ملف Google Sheet بنفس الأعمدة: الصف | المادة | الفصل | الوحدة | الدرس | نص الواجبات.
2. نزّل الجدول بصيغة JSON مضغوط أو حوّله، ثم شغّل:
   `python3 tools/parse.py questions_data.json.gz data`
3. صيغة نص الدرس: «واجب 1» ثم «صح أو خطأ» أو «الاختيار من متعدد»، ثم السؤال، ثم الخيارات (أ. ب. ج. د.)، ثم «الإجابة الصحيحة: …».
4. لإظهار رقم الصفحة: أضف حقل `p` لأي سؤال في ملفات data (الملف المصدر الحالي لا يحتوي أرقام صفحات، لذلك تعرض البطاقة «المرجع: واجب N – اسم الدرس» دون اختراع أرقام).

## قواعد اللعب المطبقة
- كل 5 ذهبيات ← سؤال واحد (يتوقف اللعب والأعداء والمؤقت).
- الإجابة الصحيحة: +100 نقطة ولا يتكرر السؤال في الجلسة.
- الإجابة الخاطئة: خصم روح واحدة فقط، لا تُكشف الإجابة، ويعود السؤال بعد 3–5 أسئلة/فرص أخرى، دون سؤال جديد بسبب هذه الروح.
- خسارة روح أثناء اللعب (حفرة/عدو/أشواك/انتهاء الوقت) ← سؤال واحد ← العودة لآخر نقطة حفظ.
- 3 أرواح لكل محاولة، شاشة انتهاء المحاولة وإعادة المرحلة بجلسة أسئلة جديدة.
- النقاط ثابتة: ذهبية 10، إجابة صحيحة 100، القفز على عدو 50، إكمال المرحلة 500.
- الحفظ محلي (localStorage): آخر مرحلة، أعلى نتيجة، أفضل عدد ذهبيات، المراحل المكتملة.
