# طيّار المعرفة 3D — لعبة تعليمية فردية

رحلة طيران ثلاثية الأبعاد بأسلوب كرتوني زاهٍ على ساحل مسقط، يتغيّر فيها الوقت من الشروق إلى الغروب:
قلعتا الجلالي والميراني ← مطرح ومبخرة ريام ← دار الأوبرا السلطانية ← جامع السلطان قابوس الأكبر ← الهبوط في مطار مسقط.

- يختار الطالب الطائرة (مروحية صغيرة / نفاثة / هليكوبتر) والطيّار (الولد أو البنتان) ويكتب اسمه اختياريًا.
- طيران حر: يظهر السؤال وتقترب حلقات ذهبية (2×2 للاختيار من متعدد، أو حلقتان لصح/خطأ)، ويطير الطالب عبر حلقة الإجابة التي يختارها.
- **صحيحة:** دفعة نفاثة و+8٪ وقود. **خاطئة:** مطبّات هوائية و−22٪ وقود؛ لا تظهر الإجابة الصحيحة، ويعود السؤال بعد 3–5 أسئلة.
- نجوم ذهبية للجمع، وغيوم يعبرها الطالب، ومناطيد وأسراب نوارس يتجنّبها (الاصطدام −8٪ وقود)، وطائرة ركاب بعيدة.
- نفاد الوقود = هبوط اضطراري في البحر وإعادة المحاولة. بعد الإجابات المطلوبة: هبوط سينمائي في مطار مسقط (أو على مهبط الهليكوبتر).
- الكاميرا خلف الطائرة أو داخل القمرة (زر 🎥 أو حرف C).
- التحكم: الأسهم أو WASD، أو السحب بالإصبع/الفأرة (عصا تحكم تظهر عند اللمس).
- الإعدادات: الإجابات للهبوط (8/12/16)، وقت الوصول إلى الحلقات (10/15/20 ثانية)، السرعة، جودة الرسوم (عالية: انعكاسات البحر وتوهّج؛ خفيفة: للهواتف).
- أصوات: محرك الطائرة حسب نوعها، الريح، موسيقى هادئة، الحلقات والنجوم والهبوط.

## التشغيل والنشر
- افتح `index.html` مباشرة (يعمل دون إنترنت؛ Three.js مضمّنة في `js/fly-engine.js`).
- يحتاج متصفحًا يدعم WebGL.
- «نسخ رابط للطلاب» و«تنزيل حزمة SCORM» في شاشة المعلم.
- مصدر المحرك في مجلد `src` (يُجمَّع بـ esbuild).
- الاختبار: شغّل خادمًا محليًا على 8810 ثم `node tests/flight3d.test.js`.
