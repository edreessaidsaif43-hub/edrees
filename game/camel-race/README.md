# سباق الجمال — لعبة تعليمية مرتبطة ببنك الأسئلة

## التشغيل
- افتح `index.html` مباشرة في المتصفح (يعمل دون إنترنت)، أو ارفع المجلد كاملًا على أي استضافة مواقع ثابتة.
- المعلم يختار: **الصف ← المادة ← الفصل الدراسي ← الوحدة ← الدروس**، ثم «إنشاء اللعبة». كل درس = سباق مستقل.

## طريقة اللعب
- الجمل يجري تلقائيًا ضد 3 متسابقين؛ يقفز الطالب فوق العوائق (الاصطدام = تعثّر دون خسارة روح).
- عند كل «بئر أسئلة» يتوقف السباق كله ويظهر سؤال (لا عوائق قرب الآبار).
- الإجابة الصحيحة: اندفاع سريع + 100 نقطة، ولا يتكرر السؤال.
- الإجابة الخاطئة: خسارة روح واحدة وتباطؤ، دون كشف الإجابة، ويعود السؤال بعد 3–5 أسئلة أخرى.
- 3 أرواح؛ عند نفادها تنتهي المحاولة. نقاط إضافية حسب المركز: الأول 300، الثاني 200، الثالث 100.

## بنية المشروع
```
index.html          الواجهات
css/style.css       التصميم
js/config.js        الإعدادات (النقاط، الأرواح، بيانات المعلم)
js/questions.js     مدير الأسئلة (منع التكرار + إعادة الخاطئ)
js/camel.js         منطق السباق والرسم
js/ui.js            الإعداد، شاشة البداية، الأسئلة، النتائج، الحفظ المحلي
js/audio.js         الموسيقى والمؤثرات
data/               بنك الأسئلة المُولّد من ملف Google Sheet
assets/characters/  صور الطالب والطالبة
tools/parse.py      تحويل ملف الأسئلة إلى ملفات data
tests/              الاختبارات
```
