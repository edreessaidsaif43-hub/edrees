# معركة الأبطال — فريق ضد فريق على شاشة العرض

## التشغيل
- افتح `index.html` مباشرة في المتصفح (يعمل دون إنترنت) واعرضه على شاشة الصف.
- المعلم يختار: **الصف ← المادة ← الفصل الدراسي ← الوحدة ← الدروس**، ثم اسمَي الفريقين وبطل كل فريق، وطاقة البطل (60/100/150)، ووقت كل سؤال.

## القواعد
- يتناوب الفريقان؛ «اعرض السؤال» (أو المسافة) ← اختيار الإجابة (أو 1–4) ← «تأكيد الإجابة» (أو Enter).
- **صحيحة:** ضربة معرفة على بطل الخصم = 20 نقطة.
  - سلسلة الإجابات المتتالية: +5 لكل إجابة متتالية (حتى +15).
  - الإجابة السريعة (في النصف الأول من الوقت): +5.
  - كل 3 إجابات متتالية: **ضربة خارقة** تضاعف الضرر.
- **خاطئة أو انتهاء الوقت:** لا ضربة، تنكسر السلسلة، وينتقل الدور؛ لا تظهر الإجابة الصحيحة، ويعود السؤال بعد 3–5 أسئلة أخرى.
- الفوز بإسقاط طاقة الخصم إلى صفر، وإذا انتهت الأسئلة يفوز صاحب الطاقة الأعلى.
- نهاية المعركة: جدول مقارنة (الطاقة، الصحيحة، الخاطئة، أطول سلسلة، الضربات الخارقة، مجموع الضرر).

## بنية المشروع
```
index.html         الواجهات
css/style.css      التصميم
js/config.js       الإعدادات (الطاقة، الضرر، المكافآت، الأوقات)
js/battle.js       منطق المعركة والواجهات والحركة
js/questions.js    مدير الأسئلة (منع التكرار + إعادة الخاطئ)
js/audio.js        الموسيقى والمؤثرات
data/              بنك الأسئلة المُولّد من ملف Google Sheet
tests/             الاختبارات (node tests/battle.test.js بعد تشغيل خادم على 8771)
```
