# أعمدة ملف Excel المدعومة

ضع عناوين الأعمدة في الصف الأول من ملف Excel، وكل صف بعده يمثل درساً واحداً.

يمكن استخدام هذه العناوين العربية:

- `المادة`
- `الصف`
- `عنوان الدرس`
- `التاريخ`
- `الحصة`
- `الأسبوع`
- `الفصل`
- `إضافة مخرج تعليمي آخر`
- `المفاهيم`
- `التهيئة / التمهيد / التعلم القبلي`
- `إجراءات سير الدرس / الأنشطة التدريسية`
- `التقويم التكويني`
- `التقويم الختامي`
- `ملاحظات ضمن خطة الدراسة الأسبوعية (يشاهدها الطالب وولي الأمر)`

الإضافة تقرأ أول ورقة في ملف `.xlsx`. بعد الاستيراد ستظهر قائمة `الدروس المستوردة` لاختيار الدرس المطلوب ثم تعبئة صفحة نور.
