# مساعد تحضير نور

إضافة Chrome محلية لتعبئة بيانات التحضير في نظام نور بدون نسخ ولصق متكرر.

## طريقة التشغيل

1. افتح Chrome.
2. اذهب إلى `chrome://extensions`.
3. فعّل `Developer mode` أو `وضع المطور`.
4. اختر `Load unpacked` أو `تحميل إضافة غير مضغوطة`.
5. اختر مجلد الإضافة.
6. افتح صفحة التحضير في نور.
7. اضغط أيقونة الإضافة، أدخل بيانات التحضير أو استورد ملف Excel، ثم اضغط `تعبئة صفحة نور`.

## استيراد ملف Excel

يمكن استيراد ملف `.xlsx` يحتوي عدة دروس. يجب أن تكون عناوين الأعمدة في الصف الأول، وكل صف بعده يمثل درساً واحداً.

الحقول الأساسية المدعومة الآن هي:

- إضافة مخرج تعليمي آخر
- المفاهيم
- التهيئة / التمهيد / التعلم القبلي
- إجراءات سير الدرس / الأنشطة التدريسية
- التقويم التكويني
- التقويم الختامي
- ملاحظات ضمن خطة الدراسة الأسبوعية (يشاهدها الطالب وولي الأمر)

راجع `EXCEL_COLUMNS.md` لمعرفة أسماء الأعمدة المدعومة.

## ملاحظات مهمة

- البيانات تحفظ محلياً داخل متصفحك فقط باستخدام `chrome.storage.local`.
- إذا تغيرت أسماء حقول نور أو كانت الصفحة تستخدم عناصر خاصة جداً، قد تحتاج مطابقة بعض الحقول يدوياً في `content.js`.
- الإضافة لا تضغط زر الحفظ في نور تلقائياً حتى تراجع البيانات قبل اعتمادها.

## الملفات

- `manifest.json`: تعريف الإضافة وصلاحياتها.
- `popup.html`: واجهة إدخال بيانات التحضير.
- `popup.css`: تنسيق واجهة الإضافة.
- `popup.js`: حفظ البيانات وإرسالها للصفحة الحالية.
- `content.js`: البحث عن حقول نور وتعبئتها.
- `styles.css`: إبراز الحقول التي تمت تعبئتها ورسالة التأكيد داخل صفحة نور.
- `EXCEL_COLUMNS.md`: أسماء أعمدة Excel التي تتعرف عليها الإضافة.
