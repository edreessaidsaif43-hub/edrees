# رحلة الفرق عبر عُمان — لعبة فرق لشاشة العرض

## التشغيل
- افتح `index.html` مباشرة في المتصفح (يعمل دون إنترنت) واعرضه على شاشة الصف.
- المعلم يختار: **الصف ← المادة ← الفصل الدراسي ← الوحدة ← الدروس**، ثم عدد الفرق (2–4) وأسماءها وشخصياتها ووقت كل سؤال.

## القواعد
- الطريق من **مسقط** إلى **خصب** عبر 22 محطة: قريات، وادي شاب، صور، رأس الحد، جعلان، مصيرة، الدقم، حاسك، مرباط، صلالة، ثمريت، هيماء، أدم، نزوى، جبل شمس، عبري، الرستاق، بركاء، صحار، شناص.
- تتناوب الفرق الأدوار. في كل دور: «اعرض السؤال» (أو مفتاح المسافة) ← يختار الفريق الإجابة ← «تأكيد الإجابة» (أو Enter).
- **صحيحة:** يرمي الفريق النرد (1–3) ويتقدّم.
- **خاطئة أو انتهاء الوقت:** لا حركة، ينتقل الدور، لا تظهر الإجابة الصحيحة، ويعود السؤال بعد 3–5 أسئلة أخرى.
- **المحطات الخاصة:** ⭐ ريح مواتية (+1)، 🌪 عاصفة رملية (−1)، 🎁 سؤال إضافي (الصحيح = +2).
- يفوز أول فريق يصل إلى خصب، وإذا انتهت أسئلة الدروس يفوز الفريق الأبعد.
- يُنصح باختيار عدة دروس (أكثر من 20 سؤالًا) لرحلة كاملة.

## بنية المشروع
```
index.html          الواجهات
css/style.css       التصميم
js/config.js        الإعدادات (عدد الفرق، الوقت، مدى النرد)
js/oman-map.js      الخريطة المبسّطة والمحطات والمفاجآت
js/oman.js          منطق اللعبة والواجهات
js/questions.js     مدير الأسئلة (منع التكرار + إعادة الخاطئ)
js/audio.js         الموسيقى والمؤثرات
data/               بنك الأسئلة المُولّد من ملف Google Sheet
tests/              الاختبارات (node tests/oman.test.js بعد تشغيل خادم على 8769)
```
ملاحظة: الخريطة رسم مبسّط تقريبي لأغراض اللعب وليست خريطة دقيقة.
